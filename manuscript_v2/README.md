# manuscript_v2/

`facts.json` holds only the aggregate main-benchmark estimates of the earlier, hypothesis-generating pilot: sensitivity and
specificity for any calcium, weighted κ, and sensitivity and specificity for Agatston ≥ 100, by reader.
`scripts/60_confirm_facts.py` reads them to build the pilot-versus-confirmatory comparison (supplementary Table S6).
The folder name is the path that script expects. No pilot participant-level data are included.
